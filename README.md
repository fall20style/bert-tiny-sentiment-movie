# 🎬 한국어 리워드 모델 (Reward Model) 파인튜닝 연구 프로토타입

본 리포지토리는 16GB RAM CPU 노트북 사양의 제한된 자원 및 완전 오프라인 환경에서 대형 한국어 BERT 모델을 파인튜닝하여, 문맥의 품질과 뉘앙스를 평가하는 **독립형 리워드 모델(Reward Model / Critic)**을 구축하고 대조 실험을 통해 성능을 검증하는 연구 공간입니다.

## 📌 핵심 연구 성과
- **100% 독립형 오프라인 파이프라인**: Hugging Face 원격 허브 주소의 스크립트 차단 정책(`RuntimeError`) 및 네트워크 방화벽 문제를 완벽히 우회하여 로컬 절대 경로 데이터 및 가중치 매핑 성공.
- **하드웨어 제약 극복 (CPU 파인튜닝)**: 475MB 체급의 대형 한국어 사전학습 BERT 모델을 활용하면서도, 데이터 다이어트 및 토큰 길이 최적화(Max Length=64)를 통해 약 **9분 19초** 만에 안정적인 수렴(`Loss: 0.73 -> 0.19`)을 달성.
- **선명한 가치 판단 경계선 확보**: 학습 전 반반 찍기(`0.53`) 수준이던 모델을 개조하여, 고품질/긍정 문장(**`0.90~0.97`**)과 저품질/부정 문장(**`0.05~0.35`**)을 양극단으로 선명하게 분리 채점하는 채점관(Critic) 정체성 확립.

## 📂 디렉터리 및 파일 구성

현재 작업 공간에서 보존 및 활용되는 최정예 핵심 인프라 구조입니다.

```text
├── local_model_base/           # 원본 475MB 한국어 특화 BERT 베이스 모델 가중치 소스
├── best_korean_reward_model/   # 파인튜닝이 완료된 나만의 한국어 리워드 모델 (핵심 결과물)
├── local_dataset_cache/        # 로컬 물리 텍스트 기반 변환 Arrow 포맷 바이너리 캐시
│
├── bert-tiny-sentiment-movie.py # 가상 배치 및 훈련 집중도를 조정하여 파인튜닝을 수행하는 메인 스크립트
├── run_inference.py            # 파인튜닝된 채점관 모델을 로드하여 실시간 보상 점수를 출력하는 스크립트
└── run_inference_base.py       # 학습되지 않은 순수 베이스 모델 사양의 대조군 추론 스크립트
```

## 🔬 실험 데이터 대조 분석 (Inference 결과)

동일한 4개의 테스트 문장 시퀀스를 입력했을 때, 파인튜닝 전후 가중치 변화에 따른 모델의 실제 보상 점수(Reward Score) 분포 차이입니다.

| 테스트 입력 문장 | 학습 안 된 베이스 모델 점수 | 파인튜닝 완료 리워드 모델 점수 | 판정 결과 |
| :--- | :---: | :---: | :---: |
| *"코드의 가독성을 높이기 위해 리팩토링을 완료했고 완벽하게 작동합니다."* | `0.5431` | **`0.9028`** | **🔥 고품질 채택** |
| *"이 영화는 연출과 스토리가 매우 탄탄해서 깊은 감동을 줍니다."* | `0.5454` | **`0.9773`** | **🔥 고품질 채택** |
| *"대충 돌아가니까 이대로 빌드하고 제출해 버려야겠습니다."* | `0.5378` | **`0.3589`** | **❌ 저품질 탈락** |
| *"배우들 연기도 어색하고 돈 아까운 최악의 지루한 영화였습니다."* | `0.5428` | **`0.0557`** | **❌ 저품질 탈락** |

### 💡 결과 해석
- **학습 전 (Base)**: 모든 문장이 `0.32 ~ 0.54` 사이에 무작위로 밀집되어 문맥의 가치나 논리성을 전혀 구별하지 못함.
- **학습 후 (Tuned)**: 긍정 및 에이전트 우수 수행 데이터에는 **90점 이상의 고득점**을 부여하고, 냉소적이거나 저품질 데이터는 **0점대에 수렴**하도록 엄격하게 필터링함.

## 🛠️ 실행 및 재학습 방법

1. **로컬 환경 클린 리셋 및 파인튜닝 진행**
   ```powershell
   Remove-Item -Recurse -Force .\local_dataset_cache -ErrorAction SilentlyContinue
   python .\bert-tiny-sentiment-movie.py
   ```
2. **개조된 고성능 리워드 채점관 모델 검증**
   ```powershell
   python .\run_inference.py
   ```
3. **순수 베이스 모델 대조군 검증**
   ```powershell
   python .\run_inference_base.py
   ```
